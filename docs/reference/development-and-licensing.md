# 開発・公開とライセンス

このページでは、株式会社NFTDriveが定める、NFTDrive対応ソフトウェアの開発・公開に関する条件を説明します。データの構造や読み戻しの方法は [NFTDriveの記録形式](./nftdrive-record-format.md) を参照してください。

## 開発・公開・販売の条件

| 対象 | 条件 |
| --- | --- |
| デコーダーの開発 | 許可は不要です |
| デコーダーの公開 | 公開前に株式会社NFTDriveの承認が必要です |
| デコーダーの販売 | 販売は自由です。ただし、公開に必要な承認を受けてください |
| 書き込みソフトウェアの開発 | NFTDriveのライセンスが必要です |

## 公認デコーダーの認定条件

公開の承認にあたっては、株式会社NFTDriveが提供する [ブラックリストAPI](https://nftdrive.net/black_list/) から取得したデータアドレス、またはMosaicに基づくフィルター機能を備えていることを確認します。承認を受けたデコーダーは、公認デコーダーとして認定されます。

このフィルターは、デコーダー側で対象データの取り扱いを制御する機能です。チェーン上の記録を削除したり、他の取得手段からのアクセスを不可能にしたりするものではありません。

## 関連特許

NFTDriveのデータ保存技術に関連して、次の日本特許を取得しています。

- 特許番号：特許第7813022号（JP7813022B2）
- 発明の名称：ブロックチェーンを用いたデータ保存システム、および、その方法
- 公報情報：[Google Patents](https://patents.google.com/patent/JP7813022B2/ja)

特許の対象範囲については、公報の「特許請求の範囲」を参照してください。
