# BEYONDとは

BEYONDは、ブロックチェーンに記録されたデータを、後から人間が検証できる形で扱うための**検証ブラウザ**です。

## 何のためのプロダクトか

ブロックチェーンには、日々多くのデータが記録されています。しかし「記録されている」ことと、「その記録が正しいと後から確認できる」ことは、同じではありません。

BEYONDは、次のような問いに人間が答えられるようにするためのプロダクトです。

- このデータの実体は、本当にチェーン上に存在するのか
- どのブロック、どのトランザクションに記録されているのか
- どのネットワークの、どのノードから取得した情報なのか
- その検証は、どのような根拠に基づいているのか

## 保存ツールではなく、検証ブラウザ

BEYONDは、データをアップロードして保管するための「保存ツール」ではありません。

保存されたデータについて、**データ実体・ブロック・トランザクション・ネットワーク情報・検証根拠**を人間が確認するためのブラウザです。

この違いは重要です。保存はデータを置く行為であり、検証はその記録の根拠を確かめる行為です。BEYONDは後者、つまり「検証可能性を人間が扱える形にする」ことに焦点を当てています。

## データ実体・ブロック・トランザクションを確認する意味

ハッシュ値だけが残っていても、元のデータ実体が失われていれば、記録の中身を確かめることはできません。逆に、データ実体があっても、それがどのブロック・どのトランザクションに紐づいているかを確認できなければ、「いつ・どこに記録されたか」の根拠が曖昧になります。

BEYONDでは、次の要素をそれぞれ確認できます。

| 確認対象 | 確認できること |
| --- | --- |
| データ実体 | 記録された中身そのものが取得・復元できるか |
| トランザクション | 誰が・いつ・どのような内容を記録したか |
| ブロック | その記録がチェーンのどこに含まれているか |
| ネットワーク情報 | どのチェーン・どのノードを根拠にしているか |

これらを個別にではなく、つながりとして確認できることが、BEYONDの中心的な機能です。

## 停止後・移行後まで含めて考える

BEYONDは、「ブロックチェーンなら永遠に安心」という立場を取りません。

ブロックチェーンにも、寿命、停止、同期不能、暗号方式の劣化、実装の消失、経済的な限界があります。だからこそBEYONDは、チェーンが**稼働している間だけでなく、停止後・移行後・再検証時まで含めて**、記録の検証可能性をどう維持するかを設計思想の中心に置いています。

この考え方は、[Chain Finalization](./advanced/chain-finalization.md) や [SnapshotProof](./advanced/snapshot-proof.md) といった仕組みにつながっています。
