# BEYONDとは

BEYONDは、ブロックチェーンに記録されたデータを、後から人間が検証できる形で扱うための**検証ブラウザ**です。

## 何のためのプロダクトか

ブロックチェーンには、日々多くのデータが記録されています。しかし、「記録されている」ことと、「その記録が正しいと後から確認できる」ことは同じではありません。

BEYONDは、次のような問いに人間が答えられるようにするためのプロダクトです。

- このデータの実体は、本当にチェーン上に存在するのか
- どのブロック、どのトランザクションに記録されているのか
- どのネットワークの、どのノードから取得した情報なのか
- その検証は、どのような根拠に基づいているのか

## 保存だけで終わらせない、検証ブラウザ

BEYONDは、ブロックチェーンへのデータ書き込みと、記録されたデータの検証を一つの環境で扱うためのプロダクトです。

重要なのは、データを書き込むこと自体ではなく、保存されたデータについて**データ実体・ブロック・トランザクション・ネットワーク情報・検証根拠**を、人間が後から確認できることです。

保存はデータを記録する行為です。

検証は、その記録がどこに存在し、どのような根拠によって確認できるのかを確かめる行為です。

BEYONDは、書き込みから取得、照合、検証までを一貫して行い、ブロックチェーン上の記録を**人間が検証可能なデータ**として扱えるようにします。

## データ実体・ブロック・トランザクションを確認する意味

ハッシュ値だけが残っていても、元のデータ実体が失われていれば、記録の中身を確かめることはできません。

逆に、データ実体があっても、それがどのブロック・どのトランザクションに紐付いているかを確認できなければ、「いつ・どこに記録されたか」の根拠は曖昧になります。

BEYONDでは、次の要素をそれぞれ確認できます。

| 確認対象 | 確認できること |
| --- | --- |
| データ実体 | 記録された中身そのものが取得・復元できるか |
| トランザクション | 誰が・いつ・どのような内容を記録したか |
| ブロック | その記録がチェーンのどこに含まれているか |
| ネットワーク情報 | どのチェーン・どのノードを根拠にしているか |

これらを個別に確認するだけではなく、それぞれの関係性をたどりながら検証できることが、BEYONDの中心的な機能です。

## 停止後・移行後まで含めて考える

BEYONDは、「ブロックチェーンは永遠に稼働するとは限らない」という立場を取ります。

ブロックチェーンにも、寿命、停止、同期不能、暗号方式の劣化、実装の消失、経済的な限界があります。

だからこそBEYONDは、チェーンが**稼働している間だけでなく、停止後・移行後・再検証時まで含めて**、記録の検証可能性をどう維持するかを設計思想の中心に置いています。

この考え方は、[Chain Finalization](./advanced/chain-finalization.md) や [SnapshotProof](./advanced/snapshot-proof.md) といった仕組みにつながっています。
