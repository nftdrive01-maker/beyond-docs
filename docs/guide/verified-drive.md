# Verified Drive

Verified Driveは、記録アドレスのオンチェーンデータを取得・復元し、検証した通常ファイルとしてWindowsへ同期するデスクトップ版の機能です。同期したファイルは、Windows Explorerや一般的なアプリケーションから利用できます。

Verified DriveはWindows専用です。Web版や、現時点で対応対象外のOSには表示されません。

## 同期の単位

同期は個別ファイルではなく、**記録アドレスとネットワークの組み合わせ**を単位に行います。同じ文字列のアドレスでも、ネットワークが異なれば別の同期領域です。

記録アドレスへ新しい記録が追加されると、次回の同期で取得対象になります。既定ではWindows上のBEYONDドライブと、実体となるドキュメントフォルダーから参照できます。

## 利用の流れ

1. Verified Browserで同期したい記録アドレスを開く。
2. Driveタブで「ローカルにマウント」を選ぶ。
3. 対象ネットワーク、保存先、自動同期の説明を確認する。
4. 取得・復元・検証が完了するまで状態を確認する。
5. Verified Driveまたは同期フォルダーからファイルを開く。

同期は起動時、一定間隔、ネットワーク再接続時、または手動操作で実行されます。取得や検証に失敗したデータは、正式なファイルとして公開せず隔離されます。既に同期済みの正常なファイルを、異なる再取得結果で自動上書きすることもありません。

## ローカル変更の検知

Verified Driveは、初回同期時に計算したSHA-256とサイズを基準に、ローカルファイルを再照合します。次の状態を検知できます。

- 同期済みファイルの内容変更
- 同期済みファイルの削除
- Dataフォルダーへの未知ファイルの追加
- 検証レポートの変更や欠落

内容変更を検知した場合、BEYONDは自動的に上書きせず、次のいずれかを利用者に求めます。

- チェーンから取得した内容へ戻す
- ローカル変更を別名で残してから戻す
- 現在のローカル内容を採用する

ローカル内容を採用すると、その内容から計算した値が以後の基準になります。これは、ローカル変更がチェーン上の記録になったことを意味しません。

## 「検証済み」の範囲

Verified Driveでは、対象ネットワークとトランザクションを確認し、記録形式を復元したうえで、復元したバイト列のハッシュをローカルの基準として保存します。

この基準値は初回取得内容から計算するTOFU（Trust On First Use）です。チェーン上に独立したコンテンツハッシュがある場合の照合とは異なり、初回取得内容そのものが正しかったことをハッシュ単独では保証できません。取得元、チャンクの完全性、トランザクションやブロックの情報も合わせて確認してください。

## 注意点

- BEYONDを終了している間はリアルタイム監視できません。起動後や定期的な全件照合で変更を検出します。
- OSのファイル監視はイベントを取りこぼす可能性があるため、定期照合も併用します。
- Verified Driveのローカル状態ファイルまで改変された場合、ローカル基準だけでは検知できない可能性があります。
- 隔離されたファイルは自動削除されません。内容を確認して手動で整理してください。
- 暗号化された記録は、復号済みの平文ではなく暗号化された封筒として保存されます。
- ドライブ表示を解除しても、明示的に削除を選ばない限り同期済みファイルは保持されます。

Verified Driveはローカル利用と改変検知を支援しますが、記録内容の真実性や端末全体の安全性を保証するものではありません。
