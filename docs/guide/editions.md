# デスクトップ版とWeb版

BEYONDには、インストールして使うデスクトップ版と、ブラウザで使うWeb版があります。基本画面は共通ですが、端末内の鍵やファイルシステムを扱う機能、ノードへの接続方法、画面を閉じた後の動作が異なります。

このページのデスクトップ版の説明は、現行のWindows版を基準にしています。ほかのOS向けのビルド設定が存在することと、そのOSで全機能が検証済みであることは同じではありません。

## 機能の違い

| 機能 | デスクトップ版 | Web版 |
| --- | --- | --- |
| Studioからの記録 | 利用可能 | 利用可能 |
| Verified Browserでの閲覧 | 利用可能 | 利用可能 |
| 新しいファイルの暗号化 | 利用可能 | 利用不可 |
| 暗号化された記録の閲覧 | 暗号化キーまたは共有パスワードで復号 | 共有パスワード付き記録と旧形式のみ復号可能 |
| Verified Drive | Windows版のみ | 利用不可 |
| LAN内ノードの検出・直接接続 | 利用可能 | 利用不可 |
| ウィンドウを閉じた後の処理継続 | タスクトレイで継続 | タブやブラウザを閉じると停止 |

## どちらを選ぶか

次の場合はデスクトップ版が適しています。

- ファイルを暗号化して記録する
- Windows上のVerified Driveへ記録を同期する
- LAN内のプライベートチェーンへ接続する
- 大きな記録処理をタスクトレイで継続する

閲覧、共有URLからの確認、通常の記録など、ブラウザ内で完結する用途ではWeb版を利用できます。ただし、大きなファイルを書き込む間はタブを閉じず、進行状態を確認してください。ブラウザやOSがバックグラウンド処理を制限する場合があります。

## ノードへの接続

- HTTPSノードは、ノード側のCORS設定が許せば両方から接続できます。
- デスクトップ版は、登録・許可されたHTTPノードやLAN内ノードへの接続をアプリ内部で中継します。
- Web版からLAN内のHTTPノードへ直接接続することはできません。
- Web版のHTTP中継は、配信環境で有効化されている場合に限り、許可された公開ノードを対象に利用できます。

接続先の制約は [Network Profile](./network-profile.md) も参照してください。

## ローカルデータとバックアップ

デスクトップ版とWeb版では、アドレス帳、設定、ジョブなどを保存する領域が別です。一方で入力した情報が、もう一方へ自動同期されることはありません。

設定のエクスポートには、すべての情報が含まれるわけではありません。未完了ジョブ、メッセージ、お気に入り、ファイル暗号化の設定などは別に扱われます。Web版ではサイトデータを削除するとブラウザ内の設定も失われるため、必要な情報を事前にエクスポートしてください。

ファイル暗号化の復旧には通常の設定エクスポートではなく、初回設定時に保管した復旧フレーズが必要です。詳しくは [ファイルを暗号化する](./file-encryption.md) を参照してください。
