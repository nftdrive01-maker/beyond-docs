# BEYONDが保証すること / 保証しないこと

このページは、BEYONDというプロダクトの誠実さの基盤となるページです。

検証を扱うプロダクトが信頼されるためには、できることを大きく見せるのではなく、できることとできないことの境界を正確に伝える必要があります。ここに書かれている内容は、BEYONDの設計と広報の両方における約束です。

## BEYONDが保証すること

BEYONDは、次のことを行います。

### データ実体と記録情報の照合を支援する

チェーンから取得したデータ実体と、記録時のハッシュ・メタデータとの照合を行い、その結果を表示します。一致すれば、取得したデータが記録時のものと同一であることの根拠になります。

### ブロック・トランザクション・ネットワーク情報の確認を支援する

記録がどのトランザクションで作成され、どのブロックに含まれ、どのネットワーク上にあるのかを、たどれる形で表示します。

### 検証手順を人間が理解しやすい形で表示する

検証の過程（何を取得し、何と照合し、どう判定したか）を、専門家でなくても追える形で提示します。「結果だけを信じてもらう」のではなく、「過程を確認できる」ことを目指しています。

### 保存された記録の根拠を確認できるようにする

「このデータは、いつ・どこに・どのように記録されたのか」という問いに対して、チェーン上の根拠を提示します。

## BEYONDが保証しないこと

一方で、次のことはBEYONDの保証の範囲外です。これらはBEYONDの欠陥ではなく、どのようなツールにも存在する境界です。

### すべてのチェーンが永遠に稼働すること

ブロックチェーンには、停止・分岐・移行の可能性があります。BEYONDはチェーンの稼働そのものを維持する立場にはありません。だからこそ、停止後の検証可能性を扱う [Chain Finalization](../advanced/chain-finalization.md) や [SnapshotProof](../advanced/snapshot-proof.md) という考え方を重視しています。

### すべてのノードが常にデータを保持すること

ノードの運用は各運用者に委ねられており、過去データを保持しないノードや、停止するノードも存在します。BEYONDはノードの可用性を保証できません。

### ユーザーが秘密鍵を失わないこと

秘密鍵の管理は利用者自身の責任範囲です。鍵を失った場合、BEYONDがそれを復元することはできません。

### 不適切に保存された個人情報の安全性

ブロックチェーンに記録されたデータは、原則として削除できません。個人情報や機微な情報を記録した場合に生じる問題を、BEYONDが解消することはできません。記録する前の判断が重要です。

### 外部システムや外部ストレージの永続性

BEYONDの検証対象の外側にある外部システム（外部ストレージ、外部API等）の稼働や永続性は、BEYONDの保証範囲外です。

### 誤ったネットワーク設定でも正しい検証ができること

意図と異なるネットワークに接続した状態では、手順として正しい検証を行っても、意図した対象の検証にはなりません。ネットワーク設定の確認は、検証の前提です（[Network Profile](../guide/network-profile.md) を参照）。

## この境界をどう受け取るか

「保証しないこと」の一覧を見て、不安に感じる方もいるかもしれません。しかし、これらの限界はBEYONDに固有のものではなく、ブロックチェーンと検証という営みそのものに伴うものです。

BEYONDの立場は次の通りです。

- 限界を隠して「安心」を演出するのではなく、限界を明示する。
- その上で、限界の中でできる最善の検証手段を、人間が扱える形で提供する。
- チェーンの停止や移行といった事態まで含めて、記録の検証可能性を設計する。

この姿勢が、長期的にBEYONDと、BEYONDで扱われる記録への信頼を支えると考えています。
