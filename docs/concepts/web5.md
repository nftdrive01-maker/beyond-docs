# WEB5とは

BEYOND／NFTDriveでは、フルオンチェーン情報を閲覧・検証・活用するWebのあり方を「WEB5」と呼びます。キーワードは **VERIFY（検証する）** です。Webサイトの公開は活用例の一つであり、WEB5はホスティングサービスの名称ではありません。

## READからVERIFYへ

| 世代 | キーワード | 定義 |
| --- | --- | --- |
| WEB1 | READ | 情報を読む時代 |
| WEB2 | WRITE | 誰もが情報を発信する時代 |
| WEB3 | OWN | デジタル資産を所有する時代 |
| WEB4 | ONCHAIN | フルオンチェーンの革新 |
| WEB5 | VERIFY | フルオンチェーン情報を閲覧・検証・活用する時代 |

この表は、BEYOND／NFTDriveの設計思想を説明するための整理です。Web全体の統一規格や厳密な年代区分を示すものではありません。読む、発信する、所有するという利用に、データ実体をチェーンへ記録し、その根拠を確かめる利用を重ねて捉えています。

## フルオンチェーンの記録を、確認できる情報へ

この整理におけるWEB4のONCHAINは、データ実体そのものをチェーンの履歴に含めることに着目します。WEB5のVERIFYは、その記録を取得・復元し、表示された内容とチェーン上の根拠との対応を利用者が確認し、活用できることに着目します。

対象はWebページに限りません。1文字のテキスト、写真、文書、制作物、組織の活動記録などにも、実体と検証根拠を結び付ける意味があります。

BEYONDは、データ実体、トランザクション、ブロック、チェーン、ネットワーク、取得元を関連付けて確認するための環境を提供します。利用者がBEYONDの表示だけを無条件に信頼するのではなく、どこから取得し、何と照合し、何を確認できたかをたどれることを重視します。

## 保存・取得・照合・検証

WEB5の利用を支える基本的な流れは、次の4段階です。

| 段階 | 行うこと |
| --- | --- |
| 保存 | データ実体や記録を永続的な媒体へ配置する。フルオンチェーンでは、データ実体を含むトランザクションをチェーンの履歴に残す |
| 取得 | 保存されたデータ実体と、トランザクションやブロックなどの情報を読み出す |
| 照合 | 取得した情報のハッシュ、識別子、参照関係などを比較する |
| 検証 | 照合結果と検証根拠から、記録の状態や検証条件を満たしているかを判断する |

画面に表示できたことと、記録との対応を確認できたことは別です。また、記録内容との一致やブロックへの包含を確認できても、内容の社会的・法的・事実的な真実性まで証明されるわけではありません。

## 検証可能性を引き継ぐ

データ実体と検証根拠を同じ履歴に保持することで、必要な履歴が取得できる場合には、記録済みデータの復元と再検証を一体として設計できます。そのためには、履歴の保持・提供、復元仕様やソフトウェアの保全、暗号化した場合の鍵の管理が必要です。

[DAOの運用](../advanced/dao-operation.md) は、参加者が担い手を交代しながら保存と検証を継続する取り組みです。[Chain Finalization](../advanced/chain-finalization.md) は、期間を定めた運用や停止・移行の後にも根拠を残すための設計です。これらを通じて、現在の利用から将来の再検証までを考えます。
