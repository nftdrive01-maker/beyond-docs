# 作業進捗

最終更新日: 2026年10月13日

## 現在の状態

`draft` ブランチで、開発リポジトリから共有された現行資料を確認し、公開ドキュメントへの統合を進めています。資料は0.9.0-beta.1時点のコードとの照合結果を含みますが、全OS・全ネットワークでの実機検証済みという意味ではありません。

内部向けの設計案、未実装API、ローカルパス、脆弱性の再現手順、過去の作業履歴は公開ドキュメントへ転載していません。利用者が必要とする現行機能、制約、安全上の注意だけを一般化して反映しています。

## 完了した内容

- Concepts全ページを「保存 → 取得 → 照合 → 検証」のモデルに統一
- 「検証可能なデータ」の定義と、データ実体からネットワークまでの検証経路を整理
- ハッシュのみ、外部ストレージ、フルオンチェーンの各方式を比較
- フルオンチェーンの容量、コスト、公開性、暗号方式、ネットワーク寿命の制約を明記
- BEYOND自身を無条件に信頼しない信頼モデルを明文化
- Network Profile、Verified Node、複数ノード照合、Trust Anchorの役割と限界を整理
- BEYONDが保証することと保証しないことを分離
- `docs/concepts/why-verification-matters.md` を追加
- 関連する用語集、Network Profile、導入ページの表現を整合
- 新規ページをConceptsカテゴリのサイドバーへ追加
- デスクトップ版とWeb版の機能差・接続方法・ローカル保存範囲を追加
- StudioのBase64／バイナリ保存、暗号化、再開、完了後の確認を更新
- ファイル暗号化の初回設定、復旧、ロック、共有パスワード、制約を追加
- Verified Browserの不完全記録、ネームスペース警告、暗号化表示、スクリプト実行の注意を追加
- Verified Driveの同期、ローカル変更検知、TOFUによる信頼境界を追加
- Blockchainsのパブリック／プライベート管理とデスクトップ版／Web版の接続差を追加
- 現行機能としてBeacon／Anchorを追加
- Chain Finalizationを実装済み機能ではなく終了設計の考え方として整理
- SnapshotProofを現行機能と誤認しない案内へ変更し、サイドバーから除外
- 記録サイズの既知の上限と、「バイナリは無制限ではない」ことを追加
- FAQ、用語集、既知の制限、保証・信頼モデルを現行機能に合わせて更新
- トップページの機能案内を現行のStudio、Verified Browser、ファイル暗号化、Verified Drive、Blockchains／Beaconへ更新

## 設計上の判断

DocusaurusにはMermaid用テーマまたはプラグインが設定されていません。設定を変更せずに表示を維持するため、検証フローはMarkdownのテキスト図として記述しています。

`verification-flow.md` は追加していません。内容の重複を避けるため、保存・取得・照合・検証の流れを `docs/concepts/verifiable-data.md` に統合しています。

## 再開時の確認事項

- 今回追加・更新した利用手順を実機UIと照合する
- 現在の配布対象OSと公開Web版の構成をリリース時に再確認する
- Mermaidを採用する場合は、Docusaurus側の設定方針を決めてから図を置き換える
- BEYOND本体の実装や仕様が更新された場合は、ファイル暗号化、Verified Drive、Beacon、保存形式の記述を再照合する
